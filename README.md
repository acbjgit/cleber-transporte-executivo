# Cleber Transporte Executivo

Mini-app/PWA para solicitação de viagens executivas pelo WhatsApp.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo: `cleber-transporte-executivo`.
2. Envie todos os arquivos desta pasta para o repositório.
3. No GitHub, vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Salve.
6. Aguarde alguns minutos.

A URL ficará parecida com:

`https://SEU-USUARIO.github.io/cleber-transporte-executivo/`

## Arquivos principais

- `index.html`: aplicativo principal.
- `manifest.webmanifest`: configuração PWA.
- `sw.js`: cache/offline básico.
- `icons/`: ícones do aplicativo.
